# GameLauncher

Консольный лаунчер для Windows.

## Использование

**Режим 1 — запуск игр со своим exe:**
```
GameLauncher.exe [путь-к-папке-с-игрой]
```
Без аргумента сканирует текущую папку и подпапки на `.exe`-файлы. Введите номер и нажмите Enter — игра запустится в своей рабочей директории.

**Режим 2 — игры без своего exe (консольные дампы, образы, ROM-файлы):**
```
GameLauncher.exe /emu
```
Откроется диалог выбора эмулятора (RPCS3 для PS3, Xenia для Xbox 360, PCSX2 для PS2 и т. д.), затем диалог выбора файла игры. Выбор эмулятора сохраняется в `launcher.ini` рядом с программой — при следующих запусках останется выбрать только файл игры.

> Файлы игры сами по себе не содержат исполняемого кода для Windows: что-то всегда должно его исполнять. Консольные дампы запускаются только через эмулятор — это и делает режим `/emu`. Используйте только дампы игр, которыми вы владеете.

## Сборка
Через GitHub Actions (`.github/workflows/build.yml`) — exe появится в артефактах запуска. Локально: `gcc gamelauncher/main.c -o GameLauncher.exe -O2 -s -lcommdlg32`.
